# Contributing

## Branch workflow

- Create feature work on a branch named `feature`.
- Merge completed feature work into `develop` for integration.
- Merge tested, ready-to-release work from `develop` into `main`.

## Dashboard changes

Keep the dashboard responsive and usable on mobile and desktop. The current project is a static HTML template; booking data is not persisted to a backend.

## Check your changes

Open `index.html` in a browser and verify the dashboard layout and any interactions you changed before merging.
